# Grooveshelf — оффлайн-проигрыватель музыки

Локальный плеер для своей фонотеки: подключаете **папки** с музыкой и **отдельные файлы** —
всё остаётся на диске, ничего не копируется, не переименовывается и не уходит в интернет.
Работает полностью без сети. Ноль зависимостей: нужен только Node.js.

## Запуск

Windows: двойной щелчок по `start.bat` (или `start-open.bat`, чтобы браузер открылся сам).
macOS / Linux:

```bash
./start.sh            # или: node server/index.js
```

Затем в открывшемся окне — кнопка **«Папка»** (подключить каталог рекурсивно)
или **«Файлы»** (добавить конкретные треки).

Нужен **Node.js 18+**. Браузер — любой современный; в Chromium доступны
перетаскивание папок из проводника и системный диалог выбора.

### Ключи запуска

```
node server/index.js [порт] [--port 7412] [--open] [--root "D:\Music"] [--host 0.0.0.0]
```

| Ключ | Что делает |
|---|---|
| `--port` | порт сервера (по умолчанию 7412; если занят — берёт следующий) |
| `--open` | сразу открыть плеер в браузере |
| `--root` | подключить папку при старте |
| `--host 0.0.0.0` | открыть доступ другим устройствам в сети (телефон, планшет) |

## Возможности

**Библиотека**
- Подключение папок (рекурсивно, со вложенными каталогами) и отдельных файлов.
- Добавление перетаскиванием: папку или файлы можно бросить прямо в окно.
- Встроенный обзор диска: выбор папки из проводника плеера, если диалог ОС недоступен.
- Автообновление при сканировании: новые файлы добавляются, удалённые — исчезают.
- Поиск по названию, исполнителю, альбому, году и пути; сортировка по любой колонке.
- Разделы: **Все треки**, **Альбомы**, **Исполнители**, **Избранное**; клик по карточке
  альбома или исполнителя проваливается внутрь.
- Группировка списка по исполнителям при сортировке «Исполнитель».
- Экспорт библиотеки в CSV, выгрузка плейлиста в `.m3u8`.

**Воспроизведение**
- Очередь с переупорядочиванием перетаскиванием, «играть следующим», очисткой.
- Перемешивание (с сохранением текущего трека), повтор: выкл / всё / один.
- Перемотка по клику и перетаскиванию полосы прогресса, буферизация, громкость, mute.
- Плавное **выравнивание громкости** (RMS-нормализация) — удобно для подборки
  треков из разных источников.
- Визуализатор спектра на Web Audio.
- Восстановление последнего трека и позиции после перезапуска.
- Медиаклавиши и системная панель воспроизведения через Media Session.

**Теги**
- Чтение: ID3v1/ID3v2.2/2.3/2.4 (MP3), Vorbis Comment (FLAC, Ogg Vorbis, Opus),
  атомов `ilst` (M4A/MP4), `LIST INFO` и `id3` (WAV). Длительность, битрейт,
  частота дискретизации, каналы, разрядность — без декодирования звука.
- Обложки: встроенные (APIC / FLAC PICTURE / MP4 covr) и файлы `cover.jpg`,
  `folder.png`, `front.*` рядом с треком; при отсутствии — аккуратная заглушка
  с инициалами.
- Редактор тегов с записью **обратно в файл** (MP3, ID3v2.3 + ID3v1). Перед первой
  правкой создаётся резервная копия `имя.mp3.bak`, запись атомарная. Для форматов
  без записи тегов изменения сохраняются в библиотеке плеера и не трогают файл.

**Интерфейс**
- Две темы: «ember» (тёмная, тёплая) и «paper» (светлая, бумажная).
- Раскладка подстраивается под узкие окна, есть боковое меню и панель очереди.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Пробел` | играть / пауза |
| `←` `→` | −5 c / +5 c (`Shift` — 30 c, `Ctrl` — 60 c) |
| `↑` `↓` | громкость |
| `N` / `P` | следующий / предыдущий трек |
| `S` / `R` | перемешивание / режим повтора |
| `M` | выключить звук |
| `F` | в избранное |
| `E` | редактировать теги |
| `Q` или `Ctrl+L` | панель очереди |
| `Enter` | играть выделенные треки |
| `/` или `Ctrl+F` | поиск |
| `Ctrl+A` | выделить всё в списке |
| `Ctrl+O` | добавить папку |
| `F5` | пересканировать библиотеку |
| `?` | список клавиш |
| `Esc` | снять выделение / закрыть окно |

## Где что лежит

```
server/           локальный сервер: API, сканер папок, парсеры тегов, раздача аудио
  index.js        маршруты HTTP, стриминг с Range, события SSE
  lib/tags.js     чтение ID3 / FLAC / Ogg / MP4 / WAV
  lib/edit-tags.js запись тегов и обложек обратно в MP3
  lib/library.js  сканирование источников, поиск, плейлисты, избранное
  lib/store.js    хранение библиотеки и настроек
web/              интерфейс: index.html, styles/app.css, js/* (ES-модули, без сборки)
data/             библиотека (library.json), настройки, папка dropped/ для
                  перетащенных в окно файлов, backups/
tests/            самопроверки (см. ниже)
```

Путь к папке данных можно изменить переменной `GROOVESHELF_DATA`.
Сервер слушает только `127.0.0.1` (если явно не указан `--host`) и раздаёт аудио
лишь из подключённых источников — произвольные файлы через API не читаются.

## Поддерживаемые форматы

Читаются и играются в браузере: **MP3, FLAC, WAV, OGG (Vorbis), Opus, M4A/MP4 (AAC), AAC, WebM/WebA**.
Определяются, но зависят от кодеков браузера: WMA, AIFF, APE, WavPack — такие треки
помечаются в списке и пропускаются при воспроизведении.

## Проверки

```bash
npm test              # все проверки
node tests/check-wiring.js      # целостность фронтенда: импорты, id, классы, иконки
node tests/check-tags.js        # парсеры тегов на реальных файлах (нужен ffmpeg)
node tests/check-write-tags.js  # запись тегов: сверка с ffprobe, откаты, утекание размера
node tests/shot.js http://127.0.0.1:7412   # скриншоты интерфейса в tests/shots/
```

`tests/fixtures.js` генерирует тестовую фонотеку через `ffmpeg` (с кириллическими
тегами, обложками, пятью форматами). Если `ffmpeg` не установлен, проверки тегов
корректно пропускаются, а проверка вёрстки работает всегда.

## Известные ограничения

- Запись тегов в файл реализована для MP3. Для FLAC/OGG/M4A правки живут в библиотеке
  плеера и в файл не пишутся (редактор честно об этом предупреждает).
- Обложку в файл можно встроить только тем же путём — для MP3.
- Перетаскивание **папок** из проводника с сохранением структуры доступно в Chromium;
  в других браузерах из окна передаются только отдельные файлы (они копируются в
  `data/dropped/`).
- Интерфейс один на всех: несколько открытых вкладок управляют одним состоянием
  библиотеки, но играют независимо.
